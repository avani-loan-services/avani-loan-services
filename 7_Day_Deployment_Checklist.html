🚀 7-Day Deployment Checklist

Avani Loan Services - AI Outbound Automation | May 13 - May 20, 2026

📅 DAY 1: Setup & Configuration

Monday - Core infrastructure verification | ⏱ 3-4 hours

  • Verify VAPI API key is set in backend environment variables
    API Key: YOUR_VAPI_API_KEY_HERE
  • Verify VAPI Assistant ID in code and environment
    Assistant ID: 9f322737-3bb8-467a-95e3-7a66f9a93dc1
  • Confirm webhook endpoint is configured
    /api/webhooks/vapi-callback
  • Enable structured data analysis in VAPI dashboard for all 6 assistants
    Settings → Assistants → Enable Analysis Plan
  • Set call timeout to 5 minutes and retry policy to 2 attempts
    VAPI Settings → Call Configuration
  • Verify Exotel business number is active
    Number: +91 9175635165 | Dashboard: Exotel
  • Create .env file with all credentials (keep secure)
    VAPI_API_KEY, VAPI_ASSISTANT_ID, EXOTEL_SID, HUBSPOT_API_KEY, etc.
✓ Day 1 Success Criteria: All API keys verified, webhook endpoint responding, VAPI assistants showing in dashboard

📅 DAY 2: CRM & Integration Setup

Tuesday - HubSpot configuration and Make.com automation | ⏱ 4-5 hours

  • [30 min] Create HubSpot custom fields
    Go to: Settings → Objects → Contacts → Custom Properties
    Create: vapi_call_id, loan_product, qualification_status, monthly_income, next_action, call_timestamp
    Refer to: HubSpot_CRM_Field_Mapping.csv for complete field list
  • [20 min] Create HubSpot pipeline stages
    Sales → Deals → Pipeline Settings
    Add: New Lead → AI Called → Qualified → Needs Review → Follow-up Scheduled → Won/Lost
  • [60 min] Configure Make.com webhook trigger
    Dashboard: make.com
    Create trigger for VAPI webhook → receives POST from /api/webhooks/vapi-callback
  • [60 min] Setup Make.com workflow: VAPI → HubSpot → Google Sheets
    Module 1: Wait for webhook from VAPI
    Module 2: Create/update contact in HubSpot
    Module 3: Append row to Google Sheets
    Module 4: Send WhatsApp (if applicable)
  • [30 min] Test Make.com workflow with 1 sample lead
    Manually trigger workflow with test data
    Verify contact appears in HubSpot
    Verify row added to Google Sheets
  • Verify Google Sheets webhook URL is accessible and logged in
    URL: Google Apps Script
✓ Day 2 Success Criteria: Make.com automation workflow created and tested successfully; HubSpot fields visible; test lead appears in both HubSpot and Google Sheets

📅 DAY 3: Website & Automation Testing

Wednesday - End-to-end testing with real interactions | ⏱ 3-4 hours

  • Test website lead form submission with 3 test entries
    Website: avanifinserv.com
    Test data: Full name, valid phone, email, loan type, amount
  • Verify forms appear in HubSpot within 5 minutes
    HubSpot Contacts → Check if new contacts created
  • Verify forms logged in Google Sheets
    Open Google Sheets → check for new rows from website submission
  • Test VAPI dashboard call trigger with test phone number
    VAPI Dashboard → Assistants → Make Call button
    Use internal test phone (ask manager for test number)
  • Verify webhook received and processed
    Check backend logs for "VAPI Webhook Received" message
    Confirm callId, duration, transcript logged
  • Test Exotel missed call automation
    Call +91 9175635165 and hang up immediately
    Verify WhatsApp callback request received within 30 seconds
  • Review sample transcripts for quality and completeness
    VAPI Dashboard → Calls → Review transcript content
✓ Day 3 Success Criteria: 3 test forms successfully synced to HubSpot; 1 VAPI call completed with webhook processed; missed call automation working

📅 DAY 4: Vercel Deployment & CI/CD

Thursday - Production deployment | ⏱ 3-4 hours

  • [30 min] Push code to GitHub repository
    git add . && git commit -m "VAPI Automation Setup"
    git push origin main
  • [30 min] Connect GitHub repo to Vercel
    Vercel Dashboard → Import Project from GitHub
    Select: avani-loan-services repo
    Framework: Vite | Build: npm run build
  • [30 min] Set environment variables in Vercel
    Settings → Environment Variables
    Add: VAPI_API_KEY, VAPI_ASSISTANT_ID, EXOTEL_SID, EXOTEL_TOKEN, HUBSPOT_API_KEY, GOOGLE_SHEETS_WEBHOOK_URL, MAKE_WEBHOOK_URL
  • [30 min] Deploy to production
    Run: npm run build && vercel deploy --prod
    Get live URL: e.g., https://avani-loan-services.vercel.app
  • Verify all endpoints accessible from production URL
    Test: /api/webhooks/vapi-callback → Should return 200 OK
    Test: /api/save-lead → Should return 200 OK
  • Update VAPI webhook URL to production endpoint
    VAPI Dashboard → Settings → Webhooks → Edit
    Update URL: https://avani-loan-services.vercel.app/api/webhooks/vapi-callback
  • Update Make.com webhook to production endpoint
    Make.com Dashboard → Scenario → Update webhook URL
  • Test full flow from production website
    Submit form on live website
    Verify data syncs to HubSpot
⚠️ Important: After updating webhook URL in VAPI, test with 1 call before scaling

📅 DAY 5: WhatsApp & SMS Setup

Friday - Communication channels | ⏱ 2-3 hours

  • [60 min] Configure WhatsApp Business API
    Option 1: Twilio → Setup WhatsApp sandbox or production number
    Option 2: Exotel → Enable WhatsApp integration
    Get WhatsApp API credentials and save to .env
  • Create WhatsApp templates
    Template 1: Loan Offer (after qualified call)
    Template 2: Appointment Reminder
    Template 3: Document Request
    Template 4: Callback Request (for missed calls)
  • Test WhatsApp send from Make.com automation
    Manually trigger workflow with test phone
    Verify message received on phone within 10 seconds
  • Configure SMS gateway
    Use Exotel SMS or Twilio SMS
    Get SMS API credentials
  • Create SMS templates
    Template: Appointment reminder (max 160 chars)
    Template: Callback request after missed call
  • Test SMS delivery
    Send test SMS to internal phone first
    Verify delivery within 30 seconds
✓ Day 5 Success Criteria: WhatsApp test message received; SMS test message delivered

📅 DAY 6: Pilot Campaign (10 Leads)

Saturday - Small-scale testing | ⏱ 4-5 hours

  • Prepare 10 test phone numbers (internal team, friends, trusted contacts)
    Verify all numbers are authentic and available
    Segment by loan type if possible (at least 2 personal, 2 business, etc.)
  • Upload leads to campaign in VAPI or via API
    Format: JSON array with phoneNumber, assistantId, loanType
  • Trigger outbound AI calls for all 10 numbers
    Use VAPI Dashboard or API batch call function
    Spread calls over 10 minutes (1 call/minute)
  • Monitor VAPI dashboard for call metrics in real-time
    Total calls: should be 10
    Completed: track which calls connected
    Duration: check average call length
  • Verify all 10 leads captured in HubSpot
    HubSpot Contacts → Filter by "Source = VAPI AI Outbound"
    Count should be 10
  • Check call transcripts and recordings
    VAPI Dashboard → Calls → Review 3-5 random calls
    Assess: clarity, conversation flow, qualification questions asked
  • Verify qualification status assigned
    HubSpot → Contacts → Check "Qualification Status" field is populated
  • Confirm WhatsApp follow-up messages sent
    Count delivery notifications in WhatsApp
    Target: 8+ of 10 delivered
  • Confirm Google Sheets has 10 entries
    Google Sheets → Count rows in AVANI_Leads sheet

📅 DAY 7: Scale to 100 Leads & Monitor

Sunday - Full campaign launch | ⏱ 6-8 hours (monitoring)

  • Prepare customer contact list (100 verified phone numbers)
    CSV format: phone, name (optional), loan_type (optional)
    Remove duplicates and invalid numbers
  • Segment leads by loan type for better script matching
    Personal Loan: ~25 leads
    Business Loan: ~20 leads
    Home Loan: ~20 leads
    Education Loan: ~15 leads
    Doctor Loan: ~15 leads
    Mortgage/LAP: ~5 leads
  • Set call spread rate: max 2 calls/minute (120 calls/hour)
    VAPI Settings → Call Configuration → Rate Limit
  • Start campaign: Day 7 morning (10:00 AM start time recommended)
    Use VAPI Dashboard or API to batch upload 100 leads
    Monitor first call in real-time before continuing
  • Monitor real-time dashboard: completion rate, avg duration, qualification %
    VAPI Dashboard → Active Campaign view
    Update every 15 minutes
  • Check HubSpot for new deals created
    HubSpot → Deals → Filter by created date = today
    Track deal creation rate
  • Monitor WhatsApp delivery and engagement
    WhatsApp Business → Message Insights
    Track delivery rate, open rate, click rate
  • Review 10 random sample transcripts for quality
    VAPI → Calls → Random sampling
    Quality checklist: greeting, questions asked, objection handled, qualification
  • Monitor system stability
    Check backend logs for errors
    Verify webhook processing all responses
  • Prepare Day 8 report with these metrics:
    Total calls dialed, completion rate, qualified rate, avg duration
    CRM sync rate, WhatsApp delivery rate, system uptime

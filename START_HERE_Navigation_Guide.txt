⚠️ COMMON ISSUES & SOLUTIONS
=============================

Webhook Not Received:
→ Check VAPI Dashboard → Settings → Webhooks → URL is correct
→ Verify backend endpoint is live and responding
→ Use Postman to test POST to webhook endpoint manually

→ Check Make.com automation logs for errors
→ Verify HubSpot API token is valid (check expiry)
→ Ensure custom fields exist in HubSpot

WhatsApp Messages Not Delivering:
→ Verify WhatsApp API credentials

Call Quality Issues:
→ Review AI prompts in VAPI assistants

→ Test with different phone types

VAPI Admin Checklist

One-page printable checklist for VAPI assistant setup, webhook configuration, and pilot launch.

1. VAPI Dashboard → Assistants

Confirm these assistants exist and are configured per loan product.

  • Avani Personal Loan Assistant
  • Avani Business Loan Assistant
  • Avani Doctor Loan Assistant
  • Avani Home Loan Assistant
  • Avani Education Loan Assistant
  • Avani Mortgage Loan Assistant

Required assistant fields

  • name
  • model.provider = openai
  • model.model = gpt-4
  • voice.provider = google
  • voice.voiceId = en-US-Neural2-A
  • firstMessage = Hi! I'm calling from Avani Loan Services...
  • systemPrompt = loan-specific qualification prompt
  • endCallMessage = Thank you for speaking with me. Have a great day!
  • recordingEnabled = true
  • analysisPlan.summaryDescription
  • analysisPlan.structuredData.enabled = true
  • analysisPlan.structuredData.fields includes:

Structured fields for each assistant:

  • customer_name
  • phone_number
  • email
  • loan_amount
  • monthly_income
  • qualification_status
  • next_action

2. VAPI Dashboard → Settings → Webhooks

  • Event Type = Call Ended
  • URL = https://<your-domain>/api/webhooks/vapi-callback
  • Method = POST
  • Active = true

For local testing, use ngrok / LocalTunnel and update the URL to the temporary secure forwarding address.

Test webhook endpoint

Endpoint:

POST /api/webhooks/vapi-callback

4. Deployment checklist

  • Confirm VAPI API key: YOUR_VAPI_API_KEY_HERE
  • Confirm assistant ID: 9f322737-3bb8-467a-95e3-7a66f9a93dc1
  • Confirm webhook URL points to backend endpoint
  • Confirm structured data fields are enabled for all assistants
  • Run one live outbound AI call and verify callback receipt
  • Confirm lead save flow to backend via /api/save-lead
  • Confirm WhatsApp follow-up works via /api/send-whatsapp
  • Confirm CRM lead path and Google Sheets logging path

5. Pilot launch plan

  • Day 0: confirm VAPI, webhook, CRM and WhatsApp paths
  • Day 1–2: test with 10 internal phone numbers
  • Day 3–4: run first 25 pilot leads and validate data
  • Day 5–7: scale to 100 leads and monitor conversion
  • Review after 100 leads: lead quality, call completion, CRM sync, WhatsApp delivery
